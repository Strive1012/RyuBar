# RyuBar 使用手册

Win11 任务栏媒体条。读系统正在播放的媒体信息（SMTC），把封面、歌词、频谱、进度直接摆在任务栏上。

---

## 零、安装

**解压即用，无需安装任何运行时。**

压缩包里只有一个 `RyuBar.exe`（约 80 MB，已内置 .NET 运行时）和本文档。
把它放到任意目录，双击运行即可。

> 体积较大的原因是**自包含**：不要求你的电脑预先装好 .NET 桌面运行时。
> 如果你已经装了 .NET 10 Desktop Runtime，体积可以降到 5 MB 左右（需另出框架依赖版）。

## 一、启动与退出

| 操作 | 结果 |
|---|---|
| 双击 `RyuBar.exe` | 启动。媒体条出现在任务栏上，托盘出现图标 |
| 右键托盘图标 → **退出 RyuBar** | 完全退出 |
| 在设置窗口点右上角 ✕ | **只关设置窗口**，媒体条继续常驻 |

程序**单实例**。重复启动不会开出第二个条子，会直接打开已有实例的设置窗口。

**首次运行**会在 `%LOCALAPPDATA%\RyuBar\` 生成：

```
settings.json        你的设置
state.json           条子的实际位置与宽度（诊断用）
settings-ui.json     设置窗口的界面状态（当前页、侧栏展开与否）
logs\ryubar.log      运行日志（排查问题用）
```

---

## 二、媒体条上有什么

从左到右：

```
[封面]  [歌词/标题]  [频谱]  [⏮ ⏸ ⏭]  [进度条]  [时间]
          ↑ 两行：当前句 + 下一句
```

**哪一项显示、哪一项隐藏，全部在设置里控制**。全部关掉也能用，只剩封面和文字。

## 三、交互

### 歌词区

| 操作 | 结果 |
|---|---|
| **单击** | 在条子上方弹出二级面板；**再点一次收起** |
| **双击** | 打开当前播放源的应用窗口（只激活**已经在运行的**，不会新开） |

### 封面

| 操作 | 结果 |
|---|---|
| 鼠标悬停 | 封面微微放大 + 叠一层高亮 + 中心出现按钮 |
| **单击** | 暂停 / 继续播放 |
| 暂停时 | 即使鼠标移开，封面中心**常驻一个播放图标**，一眼能看出没在放 |

### 控制按钮

上一首 / 播放暂停 / 下一首。播放器不支持的操作会自动置灰。

### 进度条

- **能跳转的播放器**：可以拖动，也可以直接点某处跳过去
- **不能跳转的播放器**（QQ音乐、网易云、微信等）：整条显示为**半透明禁用态**，拖不动 —— 这是刻意的，避免"拖了又弹回去"

### 滚轮

默认：**普通滚轮 = 上一首 / 下一首**，**Ctrl + 滚轮 = 切换声音来源**。可在设置 →「交互」里改。

鼠标停在哪都能用，不要求在特定区域上。

## 四、二级面板

单击歌词弹出，位置在条子正上方。

```
┌──────────────────────────────────┐
│ 大封面   曲名                      │
│          歌手                      │
│          来源：QQ音乐               │
│ ▬▬▬▬▬▬▬▬▬▬●▬▬▬▬▬▬                  │  可拖动跳转
│ 1:40                       4:36   │
│        ⏮    ⏸    ⏭              │
│ 输出设备  [扬声器 (Realtek) ▾]     │  ← 可以切换系统默认输出设备
│ 当前应用音量                 100%  │
│ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬●▬▬▬▬              │  ← 只调**当前这个播放器**的音量
└──────────────────────────────────┘
```

关闭方式：点面板外、按 `Esc`、或再点一次歌词。

**「当前应用音量」只影响正在发声的那个应用**，不动系统总音量，也不影响其它程序。它依赖应用的音频会话 —— 极少数播放器不上报会话时会无效。

## 五、设置

六个页面：

| 页面 | 内容 |
|---|---|
| **显示与位置** | 出现/收起的淡入淡出、条子宽度（自动或固定）、空档不够时压缩 |
| **外观** | 跟随系统强调色、环形进度、条状进度、控制按钮、频谱与柱数、封面进度颜色、背景不透明度 |
| **歌词** | 显示行数、逐字高亮、滚动显示、宽度（自动适配或自定义）、配色、对齐、字号、封面大小 |
| **切歌通知** | 开关、是否带封面、停留时长、位置 |
| **交互** | 滚轮动作、提示条落点与停留 |
| **应用** | 打开设置目录、版本号、退出 |

### 几处容易误会的地方

- **「歌词宽度自动适配」开 / 关**
  开 = 宽度跟着歌词内容走（上限由任务栏空档决定）；关 = 用下面的「歌词自定义宽度」固定值。
- **「环形进度」和「条状进度」可以同时开**
  两者是独立的指示器，同时开启时两种都显示。
- **「跟随系统强调色」关掉后**固定用默认蓝 `#60A5FA`。
- **「背景不透明度」调到 0** 时条子完全透明，只剩内容浮在任务栏上。

设置**即时生效**，不用重启，也不用点"保存"。


## 七、常见问题

### 歌词加载不出来

程序会依次尝试 QQ音乐、网易云、跨来源兜底。全失败时，**15 秒后**会自动重试。

如果某首歌一直没歌词，多半是词库里没有这首歌。可以看日志确认：

```powershell
Get-Content "$env:LOCALAPPDATA\RyuBar\logs\ryubar.log" | Select-String "\[lyrics\]" | Select-Object -Last 20
```

### 歌词没有逐字高亮，只有整行变色

**这是正常的。** 逐字高亮需要歌词源提供"每个字的时间轴"（QQ音乐的 QRC 格式有，网易云的纯 LRC 没有）。

有逐字数据时：字逐字推进。
没有时：**当前行整行高亮**、下一句保持暗色 —— 不去猜测每个字的演唱时间，因为那是编出来的。

### 频谱不动

1. 确认设置里「频谱」是开着的
2. 频谱数据来自**系统正在播放的声音**（WASAPI 环回），**静音时不会有柱子** —— 这是物理上的，不是 bug
3. 换了输出设备后可能需要「重新加载任务栏媒体栏」

### 双击歌词没打开播放器

只对**有独立窗口**的应用有效。UWP 应用（如系统「媒体播放器」）跑在 `ApplicationFrameHost` 里，没有自己的窗口可激活，这种情况会被跳过 —— 不会新开一个实例。

### 条子消失或位置错乱

任务栏重新加载、改分辨率、切换全屏应用后可能发生。右键托盘 → **重新加载任务栏媒体栏**。

### 设置里开关第一次点没反应

已修复（0.8.44 之后）。如果还在旧版本上遇到，升级即可。

## 八、诊断开关

一般不用管，排查问题时才有用。在启动前设置环境变量：

| 变量 | 作用 |
|---|---|
| `RYUBAR_LYRIC_TRACE=1` | 记录歌词滚动的帧率与每帧渲染耗时 |
| `RYUBAR_WIDTH_TRACE=1` | 宽度缓动的死区降到 1px，便于观察 |
| `RYUBAR_NAV_TRACE=1` | 记录设置窗口的导航与焦点状态 |
| `RYUBAR_FRAME_TRACE=1` | **每帧**输出歌词/宽度的关键量（定位"抖动/闪"这类帧级问题） |
| `RYUBAR_FORCE_MARQUEE=1` | 强制触发长句滚动（测性能用） |

在 PowerShell 里这样启动：

```powershell
$env:RYUBAR_LYRIC_TRACE='1'
.\RyuBar.exe
```

## 九、已知限制

1. **不能超出任务栏** —— 条子是任务栏的子窗口，尺寸被限制在任务栏客户区内。想要"比任务栏更高的条子"需要另一种实现方式。
2. **进度/跳转取决于播放器** —— 有些播放器（网易云、QQ音乐的部分版本）不上报时间轴，此时不显示进度，也不显示跳转操作。
3. **单应用音量依赖音频会话** —— 极少数播放器不上报会话时会无效。
4. **切歌通知**走的是系统通知通道，被系统"专注助手"拦住时不会出现。

---

## 十、卸载

1. 右键托盘 → 退出 RyuBar
2. 删除 `RyuBar.exe`
3. 删除 `%LOCALAPPDATA%\RyuBar\`（设置与缓存）

没有注册表项，没有服务，没有开机自启（如需自启，自行把快捷方式放进启动文件夹）。
